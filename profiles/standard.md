# 標準

クイックに、表示・操作・読み上げ・Lighthouseの検査を加えたプロファイル。納品前の確認はこれを基本にする。

## 目安

- 時間：5〜20分（代表ページ5件。ページの重さで変わる）
- トークン：クイックより多い（スクリーンショットを確認するため）

## クイックに加える内容

| 領域 | 内容 |
| --- | --- |
| HTMLの追加 | 構造化データ（書式・必須プロパティ）、og:title/og:description、description の重複、iframeのtitle、動画の自動再生・操作ボタン・字幕、header/nav/footer、リンクになっていない電話番号、画像のファイル名、URLの揺れ、内部リンクのリダイレクト、meta charset |
| レイアウト | 320〜1440pxでの横スクロールと原因の要素、overflow-x: hidden で隠したはみ出し、テキストの切れ、文字サイズ（10px以下・11〜13pxの本文・12px未満の割合）、100vh、タップ領域、固定ヘッダーの占有・見出しの隠れ・ページ内リンクの移動先、画像の遅延読み込み・srcset・背景画像の大きさ |
| 表示モード | ダークモードでのコントラスト、背景色と文字色の片方だけの指定、ダーク非対応時の color-scheme、ブラウザの文字サイズ設定（200%）での崩れとpx固定、行間・文字間を広げたときの切れ |
| JSが動かないとき | JavaScript無効、JSファイルの読み込み失敗で、本文が透明のまま・ローディング画面が残る |
| 読み上げ | フォーカスの枠を消すCSS、装飾記号・絵文字、同じ文言で行き先の違うリンク、日本語ページ内の英文、aria-hidden内のリンク、見た目と読み上げ順のズレ、正のtabindex、アクセシビリティツリーの書き出し |
| 公開事故 | .env・.git・バックアップなど、公開してはいけないファイルの露出 |
| フォーム | 必須項目の有無、空のまま送信、連打（二重送信）、長い入力、送信失敗時の表示。送信はすべてブラウザ内でモックし、サーバーには届けない |
| Lighthouse | アクセシビリティ・ベストプラクティス・SEO（モバイル、代表ページ2件）。スコアの合格ラインは設けず、個別の監査を4区分に振り分ける |

判定の考え方は `checks/standard-full.md`。
