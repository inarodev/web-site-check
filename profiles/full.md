# フル

標準に、時間のかかる操作・環境の検査を加えたプロファイル。公開前の最終確認や、改修前の現状把握に使う。

## 目安

- 時間：10〜40分（代表ページ8件。ページの重さで変わる）
- トークン：多い（スクリーンショットとPDFを確認するため）
- 追加の導入：WebKit（Safari相当）と Firefox（各約100MB）。入れない場合は、その検査だけ省略される

## 標準に加える内容

| 領域 | 内容 |
| --- | --- |
| 操作 | ホバー表現の有無（変化しない要素を赤い点線で示したスクリーンショット付き）、Tabキーでの到達・フォーカスの見え方・キーボードトラップ、スキップリンク、マウスでしか操作できない要素 |
| 印刷 | @media print の有無、印刷時に残る固定要素、右端の切れ、PDF化した印刷イメージ |
| 回線・外部要因 | 低速回線での LCP・CLS・読み込み時間、外部サービス（CDN・計測タグ・Webフォント）が失敗したときの表示、font-display、prefers-reduced-motion への対応 |
| 表示 | 強制ダーク（Android Chrome の「ウェブコンテンツのダークモード」）のスクリーンショット |
| ブラウザ・端末 | WebKit・Firefox でだけ出るJSエラー・横スクロール・ページの長さの差、iPhone・Android のエミュレーションのスクリーンショット |
| 公開事故 | ソースマップの公開、圧縮・キャッシュ、WordPress のユーザー名露出・xmlrpc、npm audit（high・critical） |
| Lighthouse | パフォーマンスを追加し、モバイルとPCの両方で実行（代表ページ3件）。パフォーマンスの値はローカル環境なので参考値 |

判定の考え方は `checks/standard-full.md`。
