# 要判断の質問

検出した事実（または検出できなかった事実）から、「案件によって対応が変わる項目」を質問にする。**宛先は固定しない**。案件によって、決める人（クライアント、ディレクター、自分）が変わるため。

**検出した条件に当てはまる質問だけを出す**（フォームがなければフォームの質問は出さない）。小規模なサイトで質問が多くなるときは、重要度の低いものを1項目（「その他の確認事項」）にまとめる。

判断材料は `findings.json` の `facts` にある。

| キー | 中身 |
| --- | --- |
| `analytics` | 見つかった計測タグ（なければキー自体がない） |
| `privacyPolicyLink` | プライバシーポリシーらしいリンクがあったページ |
| `formPages` | 入力欄が2つ以上あるフォームがあるページ |
| `printCss` | ページごとの @media print の有無（標準・フル） |
| `languages` | ページ内で使われている lang の値 |
| `lighthouse` | Lighthouseのスコア（標準・フル） |

書式は `検出 → 質問 → 判断の目安`。レポートの🟠 要判断に、検出理由と一緒に載せる。法的な項目は断言せず、確認事項として促す（助言ではない）。

## 共通

| 検出 | 質問 | 判断の目安 |
| --- | --- | --- |
| `@media print` がない | 印刷対応は必要か | 申込書・地図・会員証などを印刷する案件なら対応する |
| 計測タグ（GA4・タグマネージャー）が見つからない | 計測タグの設置は必要か。発行・設置は誰が行うか | 広告運用や効果測定がある案件では必須になりやすい |
| フォームがあり、プライバシーポリシーへのリンクがない | プライバシーポリシーは必要か。Cookie同意は必要か | 個人情報を取得するなら、取り扱いの掲載を確認する |
| フォームがある | 送信先アドレス、自動返信メールの文面、管理者宛メールは確定か | 送信元のSPF・DKIM・DMARCも確認する |
| `hreflang` がなく、言語別パスや複数の `lang` がある | 多言語対応は必要か | 多言語なら `hreflang` を相互に設定する |
| `og:image` がない | OGP画像の素材は支給されるか | 素材がなければ、制作側で用意するかを確認する |
| `sitemap.xml` がない | サイトマップは必要か。サーチコンソールへの送信は誰が行うか | 小規模なサイトでは任意 |
| `canonical` がない | 重複URLの扱いを指定する必要があるか | パラメータ付きURLや複数ドメインがあるなら指定する |
| ダークモードに対応していない（`color-scheme` の指定なし） | ライト専用にするか、ダークモードに対応するか | 背景色と文字色の片方だけ未指定は、🔴要修正として別に扱う |
| ブラウザ対応の方針が不明 | 対応ブラウザ・OSの範囲は決まっているか | `browserslist` や仕様書を確認する |
| 画像・フォント・ライブラリのライセンス表記が見つからない | ライセンスの確認は済んでいるか | 商用利用の可否と、クレジット表記の要否を確認する |
| 公開後のドメイン・DNS設定の情報がない | ドメインとDNSの設定は誰が担当するか | 公開日に間に合うよう、早めに確認する |

## 案件種別ごとの追加確認

案件種別は `env/detect.md` で判定する。複数該当する場合は重ねて適用する。

### EC

- 特定商取引法に基づく表記、返品・配送ポリシーへのリンクがあるか確認する
- カートから決済までの導線、在庫切れ、クーポンの挙動を確認する（⚪ 手動確認）
- 税込・税抜の表記が統一されているか
- `Product` / `Offer` の構造化データがあるか

### 会員制

- ログイン・ログアウト・パスワード再設定のメールが届くか（⚪ 手動確認）
- 未ログインで会員ページに入れないか
- セッション切れの挙動
- 会員ページに `noindex` を付けるか（意図した `noindex` は🔴でなく🟠として扱う）

### 多言語

- 言語切替リンクが対応ページに飛ぶか（トップに飛ばされないか）
- `html lang` と `hreflang` の整合
- 言語ごとのフォントと改行ルール

### LP

- 計測タグとコンバージョンの計測設定
- 広告のUTMパラメータが付いても表示が崩れないか、正しく計測されるか
- フォーム送信後のサンクスページと、その計測

### WordPress

- パーマリンク、固定ページ・投稿の公開状態、下書きの混在
- 「検索エンジンがサイトをインデックスしないようにする」設定の解除
- 不要なプラグイン・ユーザーの削除、更新状況、バックアップ
- `wp-json` や管理画面URLの露出範囲（確認までにとどめる）
