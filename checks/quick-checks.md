# クイック検査の項目と判定の考え方

クイック検査（`scripts/checks/quick.ts`）が出す項目の一覧。標準・フルで加わる項目は `standard-full.md`。スクリプトは「疑い」を機械的に出すため、レポートにする前に、文脈で誤検出を外す。

## 区分の付け方

| 区分 | 基準 |
| --- | --- |
| 🔴 要修正 | どんな案件でも直すべきもの |
| 🟠 要判断 | 案件の仕様やデザインの意図で、直すかどうかが変わるもの |
| 🟡 目視確認 | 自動では断定できず、人が見て判断するもの |
| ⚪ 手動確認 | スキルの外で行うもの |

## HTML構造

| 項目 | 基準 | 誤検出の注意 |
| --- | --- | --- |
| HTML構文 | 閉じタグ忘れ、不正なネスト、ID重複を🔴。html-validateの指摘のうち、構文に関わるルールだけを採用 | テンプレートエンジンが出す断片や、CMSが挿入するHTMLで出ることがある。出力されたHTML（ビルド後）で確認する |
| `lang` | なければ🔴（WCAG 3.1.1） | |
| `title` | なければ🔴。複数ページで同じなら🟠 | 意図した共通タイトルの場合がある |
| `main` | なければ🔴 | |
| h1 | 0個または複数で🔴 | HTML5のセクション内h1を意図的に使う案件がある。意図があれば🟠に移す |
| 見出し階層 | 2段以上の飛びを🔴 | デザイン都合で見出しレベルを変えている場合は、CSSで調整するよう提案する |
| 空の `span`/`div` | 🟠 | 装飾（背景・疑似要素の代替）で正当に使われる。クラスもIDもないものだけ検出している |
| `div`/`span` + `onclick` | 🔴 | フレームワークのイベント記法（Reactの `onClick` など）はビルド後のHTMLに残らないため検出できない。コンポーネントのソースを確認する |

## meta・SEO

| 項目 | 基準 |
| --- | --- |
| `description` | なければ🔴 |
| `viewport` | なければ🔴。`user-scalable=no` や `maximum-scale=1` があれば🔴（WCAG 1.4.4） |
| OGP画像 | `og:image` がなければ🔴。URLが取得できなければ🔴。相対パスなら🔴。`twitter:card` がなければ🟠 |
| `canonical` | なければ🟠。localhost・example.com などを指していれば🔴 |
| favicon | 宣言も `/favicon.ico` もなければ🔴。宣言があってURLが取得できなければ🔴。`apple-touch-icon` がなければ🟠 |
| `hreflang` | あるのに自己参照や `x-default` がなければ🟠。多言語の可能性があるのに `hreflang` がない場合は、`report/questions.md` の質問に回す |

## 公開前確認

| 項目 | 基準 |
| --- | --- |
| `noindex` | metaまたは `X-Robots-Tag` にあれば🔴。意図して公開しないページ（会員ページなど）は🟠に移す。意図の有無が分からないうちは🔴に置き、二重に載せない |
| `robots.txt` | `User-agent: *` で `Disallow: /` なら🔴。なければ🟠 |
| `sitemap.xml` | なければ🟠。localhost・example.com などのURLが入っていれば🔴 |
| 404 | 存在しないURLが200を返したら🟠 |
| ダミーテキスト | lorem ipsum、「ダミー」「ここにテキスト」などを🔴 |
| localhostの残り | `href` `src` `content` などに残っていれば🔴。環境変数でURLを切り替えている場合は、ビルドの設定を確認する |
| 開発用コメント | TODOなどを含むHTMLコメントを🟠 |
| 混在コンテンツ | HTTPSのページ内のHTTPリソースを🔴 |
| 401 | 認証が残っていれば⚪。検査できないページとして扱う |

## 画像

判断の詳細は `images.md`。

| 項目 | 基準 |
| --- | --- |
| `alt` | なければ🔴。ファイル名のaltも🔴（WCAG 1.1.1） |
| `width`/`height` | なければ🟠 |
| 配信形式 | JPEG/PNGで配信されていれば🔴。GIFは🟠 |
| 実寸の倍率 | 表示幅の3倍超を🔴、2倍超を🟠。ヒーロー画像・背景画像は意図して大きいことがあるため、3倍超でも🟠に下げて用途を確認してよい（通常の画像は🔴のまま） |
| サイズ | 表示面積に対して大きいものを🟠。ページ内の画像の合計が3MBを超えたら🟠 |

## リンク・フォーム

| 項目 | 基準 |
| --- | --- |
| 空リンク | `href` が空、`#`、`javascript:` を🔴 |
| 曖昧な文言 | 「こちら」「more」だけのリンクを🔴 |
| 名前がない | テキストもaria-labelもないリンク・ボタンを🔴 |
| `target="_blank"` | `rel="noopener"` がなければ🟠 |
| `tel:`/`mailto:` | 形式が不自然なものを🟠 |
| リンク切れ | 内部リンクが400以上を🔴。`--check-external` を付けたとき、外部リンクの404・410は🔴、その他の失敗は🟡 |
| フォームのラベル | `label`、`aria-label`、`title` のいずれもない入力欄を🔴。`placeholder` だけは不十分として扱う |

## 実行時（ブラウザ）

| 項目 | 基準 |
| --- | --- |
| コンソールエラー | エラーと未処理例外を🔴。広告・計測タグ由来のエラーは、外部要因として🟠に移す |
| 読み込み失敗 | 400以上や接続失敗のリソースを🔴 |

## 合格件数

スクリプトは、問題がなかった検査を「合格」として数える。レポートでは件数だけを示す（例：🟢 合格 42件）。
