# 読み上げ（スクリーンリーダー）の判断

スクリーンリーダーで不自然に読まれる可能性のある箇所を指摘する。実際の読み上げ結果は製品・設定・バージョンで変わるため、**「想定される読み」は断定せず、「〜の場合がある」と書く**。

## 指摘の書式

各指摘に、次の3点を必ず付ける。

```markdown
**全角スペースによる字間調整**
- 箇所：/contact 見出し h1「お□問□い□合□わ□せ」（□は全角スペース）
- 想定される読み：1文字ずつ区切って読まれる場合がある
- 修正案：スペースを削除し、CSSの letter-spacing で調整する（WCAG 1.3.1）
```

## スクリプトが検出するもの

| 項目 | 区分 | 想定される問題 | 修正案 |
| --- | --- | --- | --- |
| 見出し・リンク・ボタン内の全角スペース、1文字ずつの半角スペース（`C O N T A C T`） | 🔴 | 1文字ずつ読まれ、単語として認識されない場合がある | スペースを削除し、`letter-spacing` で調整 |
| HTML上で全て大文字の英単語（4文字以上） | 🔴 | 頭字語として1文字ずつ読まれる場合がある | HTMLは `Contact` と書き、CSSで `text-transform: uppercase` |
| 2〜3文字の大文字（`FAQ` `SNS` など） | 🟠 | 略語として読まれるのは正しい場合がある | 略語として意図的か確認する |
| 半角カナ | 🔴 | 環境によって読み上げが不安定 | 全角カナにする |
| 曖昧なリンク文言（「こちら」「more」） | 🔴 | リンク一覧で読まれたときに行き先が分からない | 行き先が分かる文言、または `aria-label` |
| 名前のないリンク・ボタン | 🔴 | 「ボタン」とだけ読まれる | テキストか `aria-label` を付ける |
| フォーム部品のラベルなし | 🔴 | 入力欄が何か分からない | `label for` か `aria-label` |
| `alt` の欠落・ファイル名 | 🔴 | ファイル名が読まれる、または存在が伝わらない | 内容を表す `alt`。装飾は `alt=""` |

## 誤検出の注意

- 氏名・住所の全角スペース（`山田　太郎`）は、区切りとして一般的。見出し・リンク・ボタン・ナビ・ラベル以外（本文中など）は、スクリプトの対象外にしている。対象になった場合も、区切り目的なら🟠に移す
- CSSの `text-transform: uppercase` で大文字にしている場合、HTML上は小文字なので問題ない（スクリプトはHTML上の文字だけを見る）
- 英語のみのサイトでは、大文字や英語自体は問題ではない。`lang` と文脈で判断する

## 標準で加わる項目

| 項目 | 区分 | 想定される問題 | 修正案 |
| --- | --- | --- | --- |
| 装飾記号の羅列（`★★★★☆`、`▶`、`>>`） | 🟠 | 「黒い星」「右向き三角」のように記号名が読まれる場合がある | 装飾なら aria-hidden か CSS で出す。評価は「5段階中4」とテキストで添える |
| 絵文字（📞 など。©・★のように文字として表示される記号は除く） | 🟠 | 「電話の受話器」のように名前が読まれる場合がある | 装飾なら aria-hidden="true" で囲む |
| 同じ文言で行き先の違うリンク | 🟠 | リンク一覧で区別できない | 文言を変えるか aria-label で補う |
| 日本語ページ内の英文（40文字以上でほぼ英字） | 🟠 | 日本語の発音で読まれる場合がある | lang="en" を付ける |
| aria-hidden 内のリンク・ボタン | 🔴 | フォーカスできるのに何も読まれない | aria-hidden を外すか、inert・tabindex="-1" にする |
| 見た目と読み上げ順のズレ（order、row-reverse） | 🟡 | 読み上げ・Tabキーの順番が見た目と違う | 意味のある順番ならHTMLを入れ替える |
| 正の tabindex | 🟠 | Tabキーの順番が崩れる | 0 か -1 だけにする |
| アクセシビリティツリー | 🟡 | 名前や順番が自然かは人が判断する | `aria/` のファイルを読んで確認する |

## 手動確認として固定で出す項目

- VoiceOver（macOS・iOS）で主要ページを通し読みする
- 固有名詞・社名・難読語の読みを確認する
