# 標準・フルの検査と判定の考え方

スクリプトが出すのは「疑い」。レポートにする前に、ここの注意を見て誤検出を外す、または区分を移す。

## 共通

- 重い検査は**代表ページ**だけで行う（標準5件・フル8件。`--deep-pages` で変更可）。トップを先頭に、URLの1階層目が違うページを優先して選ぶ。テンプレートが多いサイトは `--pages` で各テンプレートのページを指定すると取りこぼしが減る
- GET以外の通信（フォーム送信・計測のPOSTなど）は、すべてブラウザ内で200を返してサーバーへ届けない。ログに「モックした送信リクエスト N件」と出る
- 1つの検査が失敗しても全体は止まらず、⚪「一部の検査を実行できなかった」に出る。理由を見て、必要なら手動で確認する
- 証跡（スクリーンショット・PDF・JSON）は出力ディレクトリに保存される。🟡は証跡を見て判断する

## HTMLの追加（標準）

| 項目 | 区分 | 誤検出・判断の注意 |
| --- | --- | --- |
| 構造化データの書式 | 🔴 | |
| 構造化データの必須プロパティ | 🟠 | 種類ごとの主要なプロパティだけを見ている。Googleのリッチリザルトテストで最終確認する |
| 構造化データがない | 🟠 | 必須ではない。会社・店舗・記事などのサイトなら追加を提案する |
| og:title / og:description | 🟠 | title と description から自動で使われることも多い |
| iframeのtitle | 🔴 | |
| 動画の自動再生（音あり） | 🔴 | |
| 動画の controls・字幕 | 🟠 | 背景動画など装飾目的で muted なら字幕は対象外にしている |
| header / nav / footer | 🟠 | LPなどで意図的にない場合がある |
| 電話番号がリンクでない | 🟠 | FAXの直後の番号は除外している。PC向けの表記として残す判断もある |
| 画像のファイル名 | 🟠 | |
| URLの揺れ・内部リダイレクト | 🟠（2回以上のリダイレクトは🔴） | Next.js の trailingSlash 設定と、リンクの書き方が合っているか確認する |

## レイアウト（標準）

| 項目 | 区分 | 誤検出・判断の注意 |
| --- | --- | --- |
| 横スクロール | 🔴 | 320px は、PCでブラウザを400%に拡大した状態と同じ（WCAG 1.4.10）。原因の候補として、右端からはみ出している一番外側の要素を出す。カルーセルなど横スクロールする親の中は除外している |
| overflow-x: hidden で隠したはみ出し | 🟠 | 装飾のはみ出しを意図して隠していることも多い |
| テキストの切れ | 🟡 | text-overflow: ellipsis と line-clamp は意図した省略として除外している |
| 文字サイズ | 本文10px以下🔴 / 補足10px以下🟠 / 本文11〜13px🟡 / 12px未満が60%以上🔴 | 補足は small・figcaption・footer や、class名に note・caption・copy を含む要素で判定している |
| 100vh | 🟠 | 計算後の値が100vhのままのルールだけを出す（100svhなどで上書きしていれば出ない） |
| タップ領域 | 🟠 | 24px未満で、かつ周り（半径12px）に別のリンク・ボタンがあるものだけ。文中のリンクは対象外（WCAG 2.5.8） |
| 固定ヘッダー | 🟠 | 縦向きで25%、横向きで35%を超えたら出す |
| 見出し・本文がヘッダーに隠れる | 🔴 | ページを開いた直後（先頭）で、h1 や main 内の見出し・本文の位置にヘッダーが重なっているもの |
| ページ内リンクの移動先が隠れる | 🟠 | 固定ヘッダーがあり、移動先に scroll-margin-top も html に scroll-padding-top もないもの |
| 画像の遅延読み込み・srcset・背景画像 | 🟠 | ファーストビューの画像に lazy が付いていれば外すよう提案。背景画像は background-size: contain を除き、実寸が3倍超のもの |

## 表示モード（標準・フル）

| 項目 | 区分 | 誤検出・判断の注意 |
| --- | --- | --- |
| ダークモードで読めない | 🔴 | ライトでは読めて、ダークではコントラスト比3未満になる文字。背景画像の上の文字は判定しない |
| 背景色と文字色の片方だけ | 🔴 | html・body・:root への指定を見る。別オリジンのCSSは読めないため、その場合は判定できない |
| ダーク非対応で color-scheme もない | 🟠 | 対応するかは案件次第。しないなら color-scheme: light を勧める |
| 文字サイズ200% | はみ出し🔴 / 切れ🔴 / 固定ヘッダー🟠 / px固定🟠 | Chromium の文字サイズ設定（設定 → デザイン → フォントサイズ）と同じ仕組みで再現している。px固定のサイトは文字が大きくならないので崩れも出ないが、代わりに「px固定」として出す |
| テキスト間隔 | 🟡 | WCAG 1.4.12 の値（行間1.5倍、字間0.12em、単語間0.16em、段落後2em）を当てて新たに切れた要素 |
| 強制ダーク（フル） | 🟡 | Android Chrome と同じ仕組みで再現したスクリーンショット。黒いロゴが消えていないかなどを見る |

## 公開してはいけないファイル（標準）

.env・.git・バックアップなどを、検査対象のローカルサーバーにだけ問い合わせる。中身が本物か（.env なら `KEY=値` の行があるか）まで確かめてから🔴にする。静的HTMLのフォルダをそのままアップロードする案件では、特に事故になりやすい。

## JSが動かないとき（標準）

- 4秒待ってから判定する。CSSアニメーションで自動的に消えるローディング画面は検出しない
- 「本文が見えない」は、画面内にある本文のうち5%以上が透明・非表示のときだけ出す。閉じたメニュー・モーダル・画面外のドロワーは除外している
- JS無効（noscript が働く）と、JSファイルの読み込み失敗（noscript は働かない）を別々に見る。両方出たら原因は同じなので、レポートでは1項目にまとめてよい

## 読み上げ（標準）

`checks/screenreader.md` を参照。あわせて、:focus の outline を消していて :focus-visible の代わりもないCSSを🔴で出す（フルでは、実際にTabキーで動かして見え方も確かめる）。

## フォーム（標準）

| 項目 | 区分 | 誤検出・判断の注意 |
| --- | --- | --- |
| 連打で複数回送信 | 🔴 | 5回クリックして、送信リクエストが2回以上出たら出す |
| 空のまま送信される | 🟡 | Contact Form 7 などはサーバー側で検証するので、空でも送信リクエストが出るのが正常。エラーが返る作りなら問題ない |
| 必須項目がない | 🟠 | |
| 長い入力で崩れる | 🟡 | |
| 送信失敗時の表示がない | 🟡 | JSで送るフォームだけが対象（ページ遷移で送るフォームは、ブラウザがエラー画面を出す） |
| CAPTCHA | ⚪ | 自動では通過できない。実際に送信して確認する |

検索フォーム（role="search" や、入力欄が1つで name が s・q のもの）は対象外。

## Lighthouse（標準・フル）

- スコアは参考値として🟡に出し、合格ラインは設けない
- 個別の監査は、アクセシビリティ・ベストプラクティス・SEOで不合格（0点）なら🔴、部分的なら🟠。パフォーマンス（フルのみ）は、指標が🟡、改善提案が🟠
- ほかの検査で見ている監査（alt、lang、title、リンク名、フォントサイズ、キャッシュ、圧縮など）と、ローカル環境では意味がない監査（HTTPS、HTTP/2）は除外している
- 「手動で確認」の監査は⚪にまとめて出る
- 結果のJSONは Lighthouse Viewer（https://googlechrome.github.io/lighthouse/viewer/）で開ける

## 操作（フル）

| 項目 | 区分 | 誤検出・判断の注意 |
| --- | --- | --- |
| ホバーなし | 🟡 | 色・背景・透明度・下線・transform・影・境界線・フィルター・疑似要素の変化を比べる。ロゴや現在ページのリンク（aria-current）は意図して変えないことが多い。ヘッダー・フッターなど同じリンクは最初のページだけで調べる |
| フォーカスが見えない | 🔴 | フォーカス時に outline がなく、ほかの見た目（影・境界線・背景・文字色・下線）も変わらない要素 |
| Tabで到達しない | 🟡 | 閉じたメニューの中など、意図して除外している場合がある |
| キーボードトラップ | 🔴 | Tabを3回押しても同じ要素から動かない |
| スキップリンク | 🟠 | ヘッダー・ナビのリンクが6個以上あるのに、最初のTabでページ内リンクに移動しない |
| マウスでしか操作できない | 🔴 | cursor: pointer なのにフォーカスできない要素。装飾で cursor を変えているだけの場合もある |

## 印刷・回線・ブラウザ・公開事故（フル）

- 印刷：@media print がなければ🟠（印刷の想定があるか確認）。PDFを開いて、改ページや見出しの位置を見る
- 低速回線：ローカルなので値は小さく出やすい。LCP 4秒・読み込み15秒・CLS 0.1 を超えたら🟠
- 外部サービスの失敗：別オリジンのリクエストをすべて失敗させて、本文が見えない・ローディングが残るなら🔴
- reduced-motion：動作中のアニメーションやGSAPがあり、CSS・JSのどちらにも prefers-reduced-motion への対応が見つからないとき🟠
- ブラウザの差：Chromium にはなく WebKit・Firefox にだけ出るJSエラー・横スクロールは🔴、ページの長さが15%以上違えば🟡
- 圧縮・キャッシュ：ローカルのサーバーでは設定されないことが多い。本番URLでも確認するよう書き添える
- npm audit：本番用の依存（--omit=dev）で high・critical があれば🟠。`--project` でプロジェクトのディレクトリを渡したときだけ実行する
